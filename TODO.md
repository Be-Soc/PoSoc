# TODO: известные несогласованности, унаследованные из ветки wrong (v0.13)

Перенос выполнен дословно по источникам ветки wrong (specs/concept.md,
specs/implementation.md, specs/glossary.md); ниже — места, где сами источники
внутренне несогласованы. Решение за владельцем; до решения текст перенесён
без правки.

1. Нотация `FRIEND_REVOKE` против конвенции подписанта (§2.3, §2.8, §13 «Нотация»).
   Глоссарий задаёт: «P — подписант записи; O (other) — любой ключ, кроме
   подписанта», однако `FRIEND_REVOKE(O→P)` подписан O (отзывающий), а poison
   mark создаётся против P (§3.2.4) — роли букв в паре (O, P) противоположны
   конвенции. Обе формы присутствуют в wrong одновременно (concept §2.3/§3.2
   и glossary «Нотация»); в §2.8 sigs `[x]` при payload `{x, p, memo?}`
   использует x как подписанта-отзывателя, без ограничения x < p, наложенного
   на `FRIEND`.

2. Оценка подписной нагрузки «~2D ≈ 16–20 заявлений `MEMBER_OF` в сообщества»
   (§8) унаследована от v0.10, где глубина считалась при ширине вершины 5–10
   (D ≈ 7–10). После перехода к бинарным объединениям D = log₂(N_pop/|L0̄|)
   (§5.6.3, §9, ширина вершины 2) при больших N величина 2D превосходит
   16–20. В wrong оценка не пересчитана; сохранено значение wrong.
